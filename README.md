# Eidos Eiendomsutvikling — designprototype (Fjordbyen)

Mobile-first designløft av eidos.no med:

- **1:1-innhold** kopiert fra eidos.no (ingen endret tekst)
- Zero horizontal scroll på mobil
- AVIF/WebP responsive bilder (~150 KB mot dagens ~9,4 MB)
- Full meta/SEO + Open Graph
- Eiendommer som kort med filter + CTA
- Kontakt med hensiktsruting

Kun et demo-/tilbudsgjennm sweck for salgsmøte. Åpen via `/eidosdemo`.
